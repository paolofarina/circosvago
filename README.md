- Add source files, tests, configuration, and documentation as the project grows

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/paolofarina/circosvago.git
   cd circosvago
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux/macOS
   .venv\Scripts\activate     # Windows
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the project or tests as appropriate for the implementation.
